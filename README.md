# 小事杂货铺

> 无聊的时候，从这里随手拿一件。

一个纯静态的单页网页，专门放「无聊时可以做的小事」。
慢慢收集，慢慢做。**目标数量随便你定**，100 只是默认值。

在线版：<https://zzzzzy2k.github.io/boring-hundred/>

---

## 怎么用

**双击 `index.html`** 就能打开，不需要装任何东西、不需要联网。

数据存在浏览器的 localStorage 里，关掉网页不会丢。

### 两种玩法

| 玩法 | 怎么做 |
|---|---|
| **收集** | 想到什么就写在最上面的输入框，`Enter` 直接上架 |
| **随便来一件** | 点🎲 按钮（或按 `R`），抽一件没做过的去做 |
| **翻旧账** | 用「待做 / 做过」筛选，或按 `/` 搜索以前写下的 |
| **没灵感** | 切到「推荐清单」页，从60 条内置推荐里挑一件扔进货架 |

## 视图：我的货架 / 推荐清单

顶部的两个 tab 切换。

### 推荐清单

内置 **60 条**「无聊时可以做的事」，每行左边序号、右边「+」按钮，点一下就加入货架。

- **防重**：已经加过的会变灰并显示 ✓，加不进去
- **随机挑一件**：🎲 按钮，随机抽一条没加过的直接加进货架（加完自动切回货架页）
- **批量添加**：把当前筛选出的全部加进来，超过 12 条会先确认
- **搜索 + 属性筛选**，见下面的「属性」说明

清单里 **67% 是「不看屏幕」**的——这个产品最该帮你的事是「别总是刷手机」，所以特意多配了几条。

### 属性：三个固定维度

| 维度 | 选项 | 意义 |
|---|---|---|
| **地点** | 在家 / 室内 / 室外 | 出门还是待在家里 |
| **设备** | 无需电脑 / 用电脑 / 用手机 | 有没有电脑可用 |
| **屏幕** | 不看屏幕 / 要屏幕 | **最重要的一维**——用来提醒自己别总盯着屏幕 |

**属性和标签是两回事，不混在一起：**

- **属性**是固定的三个维度，每条最多选一个值，用来筛选
- **标签**是自由填写的（「整理」「发呆」「10分钟」），你自己定义

两个视图里都能按属性筛。货架上点搜索框右边的漏斗按钮展开。

多选时：**同一维度内单选替换，不同维度之间取交集**
（例：选「室外」+「不看屏幕」= 找出「在外面、且不用看屏幕」的事）

### 每日重复

给某条小事设成「每天重复」后，它每天自动回到未做状态。点卡片上的虚线圆圈打卡。

**设计上刻意不制造压力：**

- 打卡后显示「已连续 N 天」
- 昨天打了、今天还没打 → 显示「今天第 N 天」，不提示任何逾期
- 断签后连击**归1**，但不显示「断了」「逾期」字样
- 重复项**不弹备注框**（每天打卡不需要写感受），但可以留一行字

> 实现上不真的重置数据，而是用「最后打卡日期」和今天比较来推导显示状态——
> 这样历史记录不会因为跨天而消失。

改设置：点卡片右侧铅笔图标，编辑器里能切换重复、设置属性。

## 目标数量可以自己改

**点标题旁边的数字徽章**（如 `12 / 100`）就能直接改，或者点右上角 ⚙️ 进设置。

- 范围 1 ~ 9999
- 改完立刻生效，进度条按新目标重算
- 会跟着数据一起存下来，也会被备份带走

## 用表格收集（推荐）

批量录入比自己一条条敲快得多。设置面板里几个按钮：

| 按钮 | 作用 |
|---|---|
| **下载表格模板** | 拿到一个 CSV 模板，双击用 Excel / WPS 打开 |
| **导出为 CSV** | 把货架上现有的全部导出成表格 |
| **导入表格** | 把填好的表格导进来（`.csv` 和 `.xlsx` 都支持） |
| **导出完整备份** | 导出 JSON，**含全部字段 + 目标数量**，最完整的备份 |
| **从备份导入** | 读取 JSON 备份（可合并，不会重复） |

### 模板长什么样

| 内容 | 标签 | 重复 | 已完成 | 完成日期 | 备注 | 地点 | 设备 | 屏幕 | ID |
|---|---|---|---|---|---|---|---|---|---|
| 去楼下走一条没走过的小路 | 出门，10分钟 | | | | | 室外 | 无需电脑 | 不看屏幕 | |
| 把相册里第 100 张照片删掉 | 整理，在家 | | 是 | 2026-10-06 | 比想象中爽 | 在家 | 用手机 | 要屏幕 | |
| 拉伸十分钟 | 运动 | 每天 | | | | 在家 | 无需电脑 | 不看屏幕 | |

**只有「内容」这一列是必填的**，其余留空即可。**ID 列留空也行**，填了则导入导出能保持同一条的对应关系。

几点说明：

- **导入时会问你**：合并进现有货架（跳过内容重复的），还是清空后只留这次的。
  破坏性的那个要**点两次**才生效，不会误手。
- **表头可以改顺序、可以只留你需要的列**。程序按列名匹配（支持中文和英文），
  认不出的列会忽略。列名对不上时按位置猜：
  `内容 / 标签 / 重复 / 已完成 / 完成日期 / 备注 / 地点 / 设备 / 屏幕 / ID`。
- **日期随便写**：`2026-10-06`、`2026/10/6`、`2026年10月6日`、Excel 的日期序列号都能认。
- **「已完成」填什么都行**：`是`、`Y`、`1`、`√`、`true`、`done` 都算。
- **「重复」填 `每天` 或 `daily`** 就是每日重复项，其余值都当不重复。
- **标签用逗号分隔**：中英文逗号、顿号、空格都能识别。
- **属性列只认固定值**（`在家`/`室内`/`室外` 等），填别的会被忽略，不会导进脏数据。

## 数据备份（重要）

数据只存在**这台电脑的这个浏览器**里。清浏览器数据 / 换浏览器 / 无痕模式关窗口 = 货架清空。

**页面会在该提醒的时候提醒你**：

| 情况 | 提示 |
|---|---|
| 从没导出过 | 「还没导出过备份」+ 一键导出按钮 |
| 超过 7 天没导出 | 「距上次备份 N 天了」 |
| 超过 14 天没导出 | 「距上次备份已经 N 天了」（语气加重） |
| 点「知道了」 | 7 天内不再打扰 |

只要点了任意一个「导出」按钮，计时自动归零——**导出 CSV 也算**。

iPhone 上尤其要注意：Safari 以及添加到桌面的 PWA，都会在长期不访问时清掉本地数据。
攒到一定数量时，那条提醒就是在救你。

### 想彻底重来

设置面板 → **清空全部数据**。这是个破坏性操作，所以流程做得比较谨慎：

1. 弹窗先告诉你有多少件要清
2. 上面直接给一个**「立即导出」**按钮（点了就下载，不用先去设置面板）
3. 必须**勾选确认**才能点亮「确认清空」按钮（默认禁用，焦点还落在「取消」上）
4. 清空后 **5 秒内可以撤销**

清空时会顺带清掉「已备份时间」的记录——数据都没了，备份时间也就没有意义了。

## 装到桌面（PWA）

页面已经配好了 PWA，**不需要打包成 App**，也没有任何合规成本：

- **安卓 / 桌面 Chrome**：打开网址 → 菜单里「安装应用」或点设置里的「安装到桌面」按钮
- **iPhone Safari**：打开网址 → 分享 → 「添加到主屏幕」

装好之后：有独立图标、有启动画面、断网可用、全屏无地址栏，体验跟普通 App 几乎一样。
manifest 里还配了一个**长按图标的快捷方式「随机一件」**，点了直接抽一件事。

**本地双击 `index.html` 时不会注册离线缓存**（浏览器限制），但所有功能都正常可用——
只是没装成 App、断网打不开而已。想要完整能力，推到 GitHub Pages 就行。

### 图标是用什么画的

`tools/make-icons.py` —— **纯标准库手写 PNG 编码器**（zlib + struct），不依赖 PIL。
改配色或形状直接改那个脚本里的常量重跑即可。

图案是「一只半开的抽屉」：米色底 + 浅色抽屉面 + 陶土橙抽屉身 + 两个圆把手。
普通图标带圆角，`*-maskable-*` 版本留足了安全区（系统裁成圆形也不切到内容）。

### 关于拆分

`index.html` 已经 **2960 行**，编辑器里翻起来很吃力，所以拆出了 `app.css`（697 行）
和 `app.js`（1940 行）方便阅读和二次开发。

**但交付物永远是 `index.html` 单文件** —— 因为「双击就能用」是这个项目的核心承诺，
拆成外部文件后在某些浏览器的 `file://` 下会出问题。

所以开发流程是：

```bash
node tools/split.js    # 拆开，改app.js / app.css
node tools/bundle.js   # 改完合回去，index.html 保持完整
```

两个脚本都是幂等的，反复跑不会累积垃圾。`bundle.js` 合完会自动校验 JS 语法。

### 跑测试

```bash
npm install playwright-core
cd .dev && node e2e.js && node e2e-features.js && node e2e-xlsx.js && node e2e-pwa.js
```

## 想改点什么

| 想改 | 去哪儿 |
|---|---|
| **加/改推荐清单** | `app.js` 顶部的 `SUGGESTIONS` 数组（改完跑 `node tools/bundle.js`） |
| **加/改属性维度** | `app.js` 的 `ATTR_GROUPS`（地点/设备/屏幕三组） |
| 配色 | `app.css` 顶部 `:root` 里的 CSS 变量，暗色在 `html.dark` 那一组 |
| **图标** | 改 `tools/make-icons.py` 的配色或形状，重跑该脚本 |
| 默认目标数量 | `app.js` 里的 `var DEFAULT_GOAL = 100;` |
| 备份提醒的频率 | `app.js` 里的 `REMIND_DAYS`（7 天）和 `REMIND_DAYS_WARN`（14 天） |
| 表格的列 | `app.js` 里的 `CSV_HEAD` 和 `mapHeader()` |
| Service Worker 缓存清单 | `sw.js` 顶部的 `ASSETS` 数组 |

**改配色时注意**：反白元素（选中态 chip、实心按钮、勾选圈）不要直接用 `--accent` 配白字——
那个组合只有 2.95:1 对比度，不达 WCAG AA。代码里已经另开了一组 `--solid` / `--solid-fg` 专门干这事。

> 注意 `app.css` 只是**方便你阅读的副本**，改完要跑 `node tools/bundle.js` 合回 `index.html` 才生效。

## 部署到 GitHub Pages

**推送**：双击 `推送.bat`。首次运行会引导你完成 GitHub 认证（要一个 Personal Access Token，
获取步骤脚本里会一步步提示），之后凭据会保存下来，以后直接双击就行。

或手动：

```bash
git push -u origin main
```

**开启 Pages**：仓库 → Settings → Pages → Source 选 `main` 分支 / `(root)` → Save。
等 1~2 分钟后访问 <https://zzzzzy2k.github.io/boring-hundred/>。

> 装好 Pages 后 PWA 才能真正发挥作用——本地双击 `file://` 打开时浏览器不允许
> 注册 Service Worker，缓存功能会自动跳过。

### 如果推送失败

**`Failed to connect to github.com:443 over proxy 127.0.0.1`**

全局 git 配置里有一条指向 `127.0.0.1:7890` 的代理（Clash 的默认端口），
但代理软件没在运行。清掉它即可（这条配置已经帮你在本机删掉了）：

```bash
git config --global --unset-all "http.https://github.com.proxy"
```

**`could not read Username` / `Authentication failed`**

Token 没生成、没勾 `repo` 权限、或已过期。重新生成一个：
<https://github.com/settings/tokens> → Generate new token (classic) → 勾 `repo`。

**`Updates were rejected`**

远端有你本地没有的提交。先 `git pull origin main --rebase` 再 push。

## 技术说明

- 零依赖、零构建、零后端。双击 HTML 就跑，断网也能用（**推到 GitHub Pages 之后**断网也能用，
  本地 `file://` 打开时浏览器不允许 Service Worker，缓存功能会自动跳过）。
- **xlsx 直读是用浏览器原生 `DecompressionStream` 解 zip 实现的**，没引任何第三方库。
  老浏览器不支持时会提示「请另存为 CSV 再导入」，CSV 永远可用。
- **图标也是零依赖生成的**：`tools/make-icons.py` 手写 PNG 编码（zlib + struct），
  4x4 超采样做抗锯齿。
- 移动端做了响应式：窄屏下搜索框独占一行；手机上操作按钮常驻显示（没有 hover）。
- 无障碍：勾选圈视觉 22px 但热区撑到 44px；所有按钮有 `aria-label`；
  焦点有可见描边；尊重系统「减弱动态效果」设置；关键配色对比度按 WCAG AA 校过。
- 破坏性操作（清空、覆盖导入）一律要求二次确认，且**清空后 5 秒内可撤销**。
