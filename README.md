# 小事杂货铺

> 无聊的时候，从这里随手拿一件。

一个纯静态的单页网页，专门放「无聊时可以做的小事」。
慢慢收集，慢慢做。**目标数量随便你定**，100 只是默认值。

在线版：<https://zzzzzy2k.github.io/boring-hundred/>

---

## 怎么用

**双击 `index.html`** 就能打开，不需要装任何东西、不需要联网。

数据存在浏览器的 localStorage 里，关掉网页不会丢。

### 三种玩法

| 玩法 | 怎么做 |
|---|---|
| **收集** | 想到什么就写在最上面的输入框，`Enter` 直接上架 |
| **随便来一件** | 点 🎲 按钮（或按 `R`），抽一件没做过的去做 |
| **翻旧账** | 用「待做 / 做过」筛选，或按 `/` 搜索以前写下的 |

---

## 目标数量可以自己改

**点标题旁边的数字徽章**（如 `12 / 100`）就能直接改，或者点右上角 ⚙️ 进设置。

- 范围 1 ~ 9999
- 改完立刻生效，进度条按新目标重算
- 会跟着数据一起存下来，也会被备份带走

## 用表格收集（推荐）

批量录入比自己一条条敲快得多。设置面板里几个按钮：

| 按钮 | 作用 |
|---|---|
| **下载表格模板** | 拿到一个 CSV 模板，双击用 Excel / WPS 打开 |
| **导出为 CSV** | 把货架上现有的全部导出成表格 |
| **导入表格** | 把填好的表格导进来（`.csv` 和 `.xlsx` 都支持） |
| **导出完整备份** | 导出 JSON，**含全部字段 + 目标数量**，最完整的备份 |
| **从备份导入** | 读取 JSON 备份（可合并，不会重复） |

### 模板长什么样

| 内容 | 标签 | 已完成 | 完成日期 | 备注 | ID |
|---|---|---|---|---|---|
| 去楼下走一条没走过的小路 | 出门，10分钟 | | | | |
| 把相册里第 100 张照片删掉 | 整理，在家 | 是 | 2026-10-06 | 比想象中爽 | |

**只有「内容」这一列是必填的**，其余留空即可。

几点说明：

- **导入时会问你**：合并进现有货架（跳过内容重复的），还是清空后只留这次的。
  破坏性的那个要**点两次**才生效，不会误手。
- **表头可以改顺序、可以只留你需要的列**。程序按列名匹配（支持中文和英文），
  认不出的列会忽略。列名对不上时按位置猜：`内容 / 标签 / 已完成 / 完成日期 / 备注 / ID`。
- **日期随便写**：`2026-10-06`、`2026/10/6`、`2026年10月6日`、Excel 的日期序列号都能认。
- **「已完成」填什么都行**：`是`、`Y`、`1`、`√`、`true`、`done` 都算。
- **标签用逗号分隔**：中英文逗号、顿号、空格都能识别。

## 数据备份（重要）

数据只存在**这台电脑的这个浏览器**里。清浏览器数据 / 换浏览器 / 无痕模式关窗口 = 货架清空。

建议每隔一段时间点一次「导出完整备份」。文件名自动带日期。

## 主题外观

右上角有太阳/月亮图标，点一下切换。设置面板里可选三档：

- **跟随系统**（默认）：系统开暗色就自动暗色
- **亮色**
- **暗色**

暗色不是简单反色——色板是单独调过的暖调深色，和亮色同一气质，不是冷灰。

### 代码长了怎么办

`index.html` 目前约 **1790 行**。
**超过 2200 行时就该拆了**，拆分方案按这个顺序：

1. `index.html` —— 只留 HTML 骨架，删掉 `<style>` 和 `<script>`
2. `app.css` —— 把 `<style>` 里的内容原样搬过去
3. `app.js` —— 把 `<script>` 里的内容原样搬过去
4. 用 `<link rel="stylesheet" href="app.css">` 和 `<script src="app.js"></script>` 引回来

CSS 已经用注释分好 11 个区块（Design Tokens / Reset / Header / Composer / Toolbar /
List / Modal / Toast / Footer / Responsive / A11y），按区块整段搬就行，不用重新梳理。

**拆完双击依然能开**，不需要起本地服务器。

## 想改点什么

| 想改 | 去哪儿 |
|---|---|
| 配色 | `index.html` 顶部 `:root` 里的 CSS 变量，暗色在 `html.dark` 那一组 |
| 默认目标数量 | JS 里的 `var DEFAULT_GOAL = 100;` |
| 表格的列 | JS 里的 `CSV_HEAD` 和 `mapHeader()` |

**改配色时注意**：反白元素（选中态 chip、实心按钮、勾选圈）不要直接用 `--accent` 配白字——
那个组合只有 2.95:1 对比度，不达 WCAG AA。代码里已经另开了一组 `--solid` / `--solid-fg` 专门干这事。

## 技术说明

- 零依赖、零构建、零后端。双击 HTML 就跑，断网也能用。
- **xlsx 直读是用浏览器原生 `DecompressionStream` 解 zip 实现的**，没引任何第三方库。
  老浏览器不支持时会提示「请另存为 CSV 再导入」，CSV 永远可用。
- 移动端做了响应式：窄屏下搜索框独占一行；手机上操作按钮常驻显示（没有 hover）。
- 无障碍：勾选圈视觉 22px 但热区撑到 44px；所有按钮有 `aria-label`；
  焦点有可见描边；尊重系统「减弱动态效果」设置；关键配色对比度按 WCAG AA 校过。
